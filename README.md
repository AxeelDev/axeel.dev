# Axel’s portfolio

The site at [axelp.dev](https://axelp.dev). A quiet reading column on a forest background: an introduction, selected projects, writing, the tools I use, and a short about section. The public pages are for reading. Changes happen in a private editor.

## On the site

- **Home** brings together the introduction, selected work, recent writing, tools, and about text.
- **Projects** shows larger pieces with screenshots, then a compact list of smaller ones. Each project has notes and links.
- **Writing** is a set of posts. Drafts stay private until they are published.
- **Uses** lists tools in groups, with a short note on each.
- The **editor** is signed-in only. It updates projects, posts, tools, groups, and the profile, including Estonian and German versions.

The site can sit in light or dark, and the switch is animated. The first visit has a brief entrance. When the browser asks for reduced motion, that movement stays off.
